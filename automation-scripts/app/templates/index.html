What is this site for?

This is a dashboard for manually running small, pre-registered utility scripts—not a scheduler. Choose one to inspect disk space, inventory project files, check the Python environment, or try the system and log-analysis demos.

Each script runs on the computer hosting this app. The app saves its output and run time in History. The SSH analyzer reads only the bundled sample log; it does not monitor live logins or block IPs. The original System Health Check needs Linux/Bash, while the new Python utilities work across operating systems.

Only run this app and its scripts on a computer you own or are authorized to manage. The added inventory, disk, and environment utilities are read-only: they do not change files or settings.
